平衡兩分類資料之續貫(垂直)堆疊整合學習演算法

BCS-Stacking: Vertical Sequential Stacking for Balanced Binary Classification
許博翔、顏畯榤、張妍婷、柯廷翰、陳宗揚、葉芷儀、韋葶妤、倪佩榆
指導教授：李名鏞 教授
📋 摘要 Abstract

本研究提出一種新型態的垂直堆疊整合學習框架，針對平衡二分類資料，透過雙門檻機制（θ₁, θ₂）將樣本劃分為確定區與難分類區（Λ），並結合多層順序堆疊策略，有效提升分類準確率與模型穩定性。

核心貢獻：
  • 提出雙門檻決策機制
  • 整合 16 種基礎模型
  • 發展 4 種堆疊策略
  • 在多項指標上超越傳統方法
🎯 研究動機

傳統堆疊方法存在以下限制：

  • 機率加權的模糊性：水平堆疊忽略模型在不同樣本上的確定性差異
  • 缺乏順序性：未考慮基礎模型的強弱順序與互補關係
  • 難分類樣本處理不足：對邊界樣本缺乏針對性策略

本研究旨在發展一套能動態識別難分類樣本，並依序调用不同模型專精處理的整合框架。

📊 資料集
UCI White Wine Quality Dataset

資料規模：4,898 筆樣本

特徵維度：11 項理化指標

  • 固定酸度、揮發性酸度、檸檬酸
  • 殘糖量、氯化物、二氧化硫
  • 密度、酸鹼值、硝酸鹽、酒精濃度

類別分布：

  • Class 0（普通）：1,640 筆 (33.48%)
  • Class 1（優質）：3,258 筆 (66.52%)
🔧 方法論

基礎模型：16 種機器學習演算法

  • 樹模型：Random Forest, Extra Trees, Decision Tree, Pruned Tree
  • Boosting：XGBoost, LightGBM, CatBoost, AdaBoost, Gradient Boosting
  • 線性模型：Logistic Regression (L1/L2), ElasticNet, Linear SVM
  • 其他：KNN, Naive Bayes

堆疊策略：

  1. 完全自動搜索（80% 純度門檻）
  2. 個別模型設定純度
  3. 手動指定門檻
  4. 邏輯斯回歸元模型
⚙️ 工作流程
🎯 雙門檻機制

透過雙門檻將預測空間分為三區，針對難分類樣本（Λ）調用專精模型處理。

  • LightGBM: ROC-AUC 0.8154
  • KNN: ROC-AUC 0.8134

方法 MCC ROC-AUC 覆蓋率

方式二（個別模型設定純度）在 MCC 指標上表現最佳，顯示其分類平衡性最優。

💡 關鍵發現
1. 雙門檻機制有效性

能成功識別 9.71%–54.22% 的難分類樣本，並針對性處理。

2. 順序堆疊優勢

方式二 MCC 達 0.4870，較最佳單模型（LightGBM 0.4806）提升 1.33%。

3. 覆蓋率與效能權衡

方式二覆蓋率僅 45.78%，但準確率最高，顯示「少而精」策略有效。

4. 邏輯斯回歸穩定性

雖 MCC 略低，但 100% 覆蓋率確保所有樣本皆被分類，適合實務應用。
